# Документация Dota 1x6 Overlay

Короткое руководство: как пользоваться, что означают цифры и как устроен проект.

## Что это

Отдельное приложение-оверлей поверх Dota 2. Показывает статистику игроков
[Dota 1x6](https://dota1x6.com) до начала матча. Игра и кастомка не изменяются:
оверлей просто висит окном поверх Dota и берёт данные с публичного API сайта.

## Установка

**Готовая сборка (рекомендуется)** — [Releases](https://github.com/dig-png/dota1x6-overlay/releases):

- `Dota1x6Overlay-Setup-<версия>.exe` — установщик;
- `Dota1x6Overlay-Portable-<версия>.exe` — портативная версия.

Сборка не подписана: при первом запуске SmartScreen → «Подробнее» → «Выполнить всё равно».

**Из исходников:** нужен Node.js 20+.

```powershell
npm install
npm start
```

## Использование

1. Запусти оверлей — окно появится справа сверху.
2. В Dota 2 включи режим **«Оконный без рамки»** (Настройки → Видео).
3. Вставь в поле данные игроков: `SteamID64`, `account_id`, `STEAM_0:x:y`, `[U:1:x]`
   или ссылку на профиль Steam. Можно несколько — по одному в строке или через запятую.
4. Нажми **Загрузить** или `Ctrl+Enter`.
5. `F9` — режим «клик-сквозь», чтобы мышь проходила в игру. `F8` — скрыть/показать.

Клик по карточке открывает профиль игрока на dota1x6.com.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F8` | скрыть / показать оверлей |
| `F9` | клик-сквозь вкл/выкл |
| `Ctrl +` / `Ctrl -` | масштаб интерфейса (по умолчанию 115%) |
| `Ctrl 0` | сбросить масштаб |
| `Ctrl+Enter` | загрузить статистику |
| `Ctrl+Shift+X` | закрыть приложение |

## Что означают цифры

| Поле | Значение |
|---|---|
| Рейтинг | текущий рейтинг игрока в Dota 1x6 |
| #N в ладдере | место в топ-50 (для остальных не показывается — API отдаёт только топ-50) |
| Матчи | всего сыгранных матчей |
| Ср. место | среднее место в матчах (1 — победа, 6 — последнее) |
| 1-е места | доля матчей, где игрок занял первое место |
| В топ-3 | доля матчей с местом 1–3 |
| Дуо | рейтинг в парном режиме |
| Пул героев | герои из последних 50 матчей: сколько игр, ср. место и винрейт в тултипе |
| Плашки внизу | последние 6 игр: номер места и изменение рейтинга в тултипе |

## Как это работает

- **Electron**: `main.js` — окно, хоткеи, IPC; `preload.js` — безопасный мост;
  `renderer/` — интерфейс; `lib/api.js` — запросы и агрегация.
- Окно прозрачное, без рамки, `always-on-top` уровня `screen-saver`, не показывается в таскбаре.
- Данные запрашиваются в момент нажатия «Загрузить». **Кэша нет** — каждый раз свежие данные.
- Используется публичный API без ключей и авторизации:

```
https://stats.dota1x6.com/api/v2/players?playerId=<account_id>
https://stats.dota1x6.com/api/v2/players/steam-profile?playerId=<account_id>
https://stats.dota1x6.com/api/v2/matches/history?playerId=<account_id>&page=1&count=25
https://stats.dota1x6.com/api/v2/leaderboard
```

`account_id` — 32-битный ID Steam (не SteamID64). Оверлей конвертирует SteamID64,
`STEAM_0:x:y` и ссылки автоматически; vanity-ссылки (`/id/...`) резолвятся через Steam.

## Структура проекта

```
main.js              окно, always-on-top, хоткеи, IPC
preload.js           мост renderer ↔ main
lib/api.js           парсинг ID, API, пул героев
renderer/            index.html, style.css, app.js
scripts/             тест API, скриншот, генерация иконки
build/icon.png       иконка приложения
.github/workflows/   сборка и публикация релизов
```

## Сборка и релизы

```powershell
npm run dist            # установщик + портативный exe в dist/
npm run dist:portable   # только портативный exe
npm run test:api        # проверка API и парсинга ID
```

Релиз публикуется автоматически по тегу:

```powershell
npm version patch
git push --follow-tags
```

GitHub Actions соберёт оба `.exe` и приложит их к релизу.

## Ограничения

- Состав лобби вводится вручную: Dota 2 не отдаёт список игроков сторонним приложениям.
- Ладдер — только топ-50; пул героев — последние 50 матчей.
- Показываются только игроки, зарегистрированные на dota1x6.com.
- Оверлей не виден в эксклюзивном полноэкранном режиме.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Оверлея не видно в игре | Включи «Оконный без рамки» в настройках Dota 2 |
| SmartScreen блокирует запуск | «Подробнее» → «Выполнить всё равно» (сборка не подписана) |
| «Игрок не найден на dota1x6» | Игрок не регистрировался на сайте или передан неверный ID |
| «Сайт dota1x6 недоступен» | Нет интернета или сайт временно недоступен — попробуй позже |
| Мышь не попадает в игру | Нажми `F9` (клик-сквозь) |
| Интерфейс мелкий/крупный | `Ctrl +` / `Ctrl -`, сброс — `Ctrl 0` |
